# Project Documentation Evidence Package

This folder is an evidence-based documentation package for the AI-Based Career Guidance System. It describes only behavior that can be traced to repository source files reviewed during the audit.

Use these files when drafting the final university report:

- `01` to `04` for the introduction, requirements, architecture, and module descriptions.
- `05` and `06` for database and API chapters.
- `07` to `14` for implementation chapters on security, AI, resume analysis, skill gap analysis, recommendations, learning paths, advisor chat, and dashboard.
- `15` and `16` for frontend and testing sections.
- `17` and `18` for limitations, future work, traceability, and claims review.

Manual evidence still needed: running-system screenshots, deployment/environment details, populated MongoDB collections, API responses, Gemini output samples, and usability or test-session evidence.

Do not claim without further evidence: successful test execution, production deployment, database seed/import process, the provenance or currentness of salary/market data, encryption at rest, HTTPS, rate limiting, role-based authorization, password-reset flows, persistent chat history, or accuracy metrics for Gemini output.

The `18-documentation-evidence.md` table maps important claims to the relevant source files and marks gaps as **Requires confirmation**.
